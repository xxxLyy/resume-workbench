# 脱敏历史编辑器主脚本夹具（DEL-01）

- `editor-current.js`：来源 git `0c3fed0` 的 template.html 编辑器主脚本。
- `editor-legacy-region-tab.js`：来源 git `72cd098` 的 template.html 编辑器主脚本。

两份都是**逐字**的脚本内容（只把 `var DOC_ID = '…';` 归一化为 `{{DOC_ID}}` 占位符）——
服务端算 CSP 指纹时对 DOC_ID 做同样归一化，因此占位符版本与原文指纹一致。
**不要在这些文件里加注释或改动任何字符**：内容一变，指纹就不再匹配白名单，
严格 CSP 会（正确地）拒绝该脚本。

脚本只含通用编辑器逻辑，不含任何个人数据；测试不依赖个人文档，也不依赖动态 Git 历史
（夹具已固化在本目录）。
