>
> **Goal:** 冻结渲染契约与数据一致性地基：完整资源指纹的 freeze/归一化单一出口、覆盖进程中断的保存事务与共享 meta 原子更新、全部渲染/编辑入口统一组装、主题装配共用函数、RGB 视觉门禁、schemaVersion 迁移、状态维度与不可变导出记录。

> **Tech Stack:** Node ESM、playwright-core 1.60.0（pin）、poppler（pdftotext/pdfinfo/pdftoppm）、ffmpeg（rgb24 raw 像素比对）、bash 测试套件。

> **v2 修订（2026-09-25 评审）**：资源指纹完整哈希+远程拒绝；/pdf 废直渲、/edit 注入 typo；updateMeta 原子入口+跨进程锁+并发 B 后注入用例；视觉门禁前置且检查器缺失即停；验证命令 pipefail/直跑+负向夹具；模板装配全调用点；导出按钮/并发/恢复/投递 exportId；RGB24 比较+ffmpeg 环境检查；归一化 HTML 幂等断言；重渲不要求 PDF md5。任务顺序改为：冻结与资源指纹 → 保存事务及共享 meta → 全部渲染/编辑入口 → 主题装配 → 视觉工具 → 完整迁移 → 状态与导出 → 隔离验收 → 停服务或排他锁后真实迁移。

## Global Constraints（逐字摘自 spec v3.1，所有任务默认包含）

- 铁律一：当前文档渲染 = 当前 HTML + 该文档当前 meta；铁律二：快照、投递存档及任意 `--src` 渲染只使用冻结文件内容与样式，**绝不读取当前文档 meta**；render.mjs 保持 meta-blind。
- 冻结文件内联 typo、自包含、只读；当前文档落盘不含 typo，值只存 meta；复制/回滚先读冻结样式再**归一化为当前格式**；不存在"已有 typo 就跳过注入"分支。
- 资源指纹 = 完整内容哈希：内嵌 data: 哈希完整数据、本地文件哈希文件内容；http(s) 远程 URL = 不可复现输入（freezeHtml 返回 remote[]；POST /export 拒绝；旁车 reproducible:false）；禁用前缀截断。
- 保存与迁移覆盖异常**与进程中断**：`.tx/` 事务记录 + 启动/重跑恢复（只恢复目标文档）；无 tx 且 schemaVersion<2 = 首次迁移不回滚历史快照；共享 docs-meta 一律经 `updateMeta` 原子更新；迁移/保存持跨进程排他锁 `<root>/.migrate.lock`，server 见锁写请求 503。
- renderInputId = sha1(bodyHash:cssHash:typoHash:resourcesHash) 含正文；任务启动冻结输入、成功记该任务标识；mtime 不作正确性依据；/pdf、/export、POST /render、首页、GET /edit 共用组装与 staleInfo。
- 导出仅 POST /export 记录；产物 `pdfs/history/<id>@<renderInputId>.pdf` 完整哈希、存在即复用禁止覆盖；exports[] 含 exportId/snapTs/完整 renderInputId；投递绑定所选 exportId 不重冻后来正文；配额清理豁免被引用的冻结 HTML/manifest/资源。
- 状态：存储 kind/flow/archivedAt；可投递派生；deliveredRefs/usedBy 读取时从 applications.json 派生不存储；迁移删除 job.status。
- data-editor 仍 v5；schemaVersion 1→2；不同字段。
- 视觉门禁 = 文本层 0 差异 + 页数同 + **RGB24** 逐字节 diff/total ≤0.5%（DPI 150）；检查器缺失 = 停止提交不降级；迁移三项全过才写 done。
- 验证纪律：直接运行测试或 `bash -o pipefail -c '… | tail'`；禁止裸管道吞退出码；隔离夹具含负向验证。
- 重渲验收 = 冻结输入不变 + 文本/页数/固定环境视觉一致，**不要求 PDF md5 相同**；仅"直接复用既有不可变文件"才校验文件哈希。
- 不升级 playwright-core；不改 render.mjs 原子替换纪律；测试隔离 RESUME_ROOT（Task 10 真实迁移除外，先隔离副本验证）；提交中文动宾、不 amend 不 rebase。
