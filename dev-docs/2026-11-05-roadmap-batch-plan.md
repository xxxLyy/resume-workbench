## 3. 批 2 · ATS 诚实检查包

- **确定性内容检查**（S4a ⑪ 补课，纯规则零 AI）：六类——①公司/项目名写法不一致 ②日期格式不统一或明显倒序 ③联系方式格式异常 ④链接格式错误 ⑤重复段落 ⑥未替换占位符；三级分类（需修复/建议核对/风格建议）；落点=导出检查卡新分区，校验阶段共用同一实现（单一通道）
- **文本层预览**：导出页折叠区「机器读到的样子」= 服务端 pdftotext 结果原样展示（能力已存在，纯展示）；无分数无结论
- 「熟悉/精通」大量重复仅风格建议（路线图原口径）；不做 ATS 打分/录用概率（明确不做）

## 4. 批 3 · S8 网申包 + 跟进助手

- 新页 `/apply-profile` + topnav 第七项「网申包」；数据 `RESUME_ROOT/apply-profiles.json`（通用表+按公司包），结构迁移走既有 tx 纪律
- 字段三态：**跟随来源**（母版派生纯文本，来源变更标漂移）/ **手动覆写** / **恢复跟随**；期望薪资等独立字段不从简历派生
- **AI 文案字段**（新增类型）：打招呼语/自荐信/跟进语——走既有 genTasks（进度/取消/真实用量），生成→预览→确认才入字段包；覆写后锁定不覆盖
- 单字段一键复制 + 整包导出（纯文本/JSON）；投递记录关联所用字段包
- **跟进助手**：投递卡「无回应超 N 天（默认 7，可配）」→ 生成跟进语草稿按钮；与逾期提醒并存
- **分享副本**：勾选隐藏字段 → 独立预览/PDF，导出前文本层校验无残留（复用批 2）
- 不做跨站注入/自动发送（硬约束）

## 5. 批 4 · 面试练习包

- 出题：复用面试追问生成（kind=interview 基建，按 JD+证据表预判）
- 练习：逐题文本作答 → AI 对照证据表反馈（答到的事实/缺的指标/夸大倾向）→ 逐题改进建议
- 反哺：缺的素材一键转「待补充素材」（materials 轻量关联）
- 记录：练习历史随投递持久化（截 20，复用 F3 模式）；诚实口径：无百分位、无「超过 X% 候选人」
- 入口：投递详情面试准备区 + 复盘页；语音作答不在本轮（S7a 未选）
