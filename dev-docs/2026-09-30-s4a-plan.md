**Goal:** 在既有岗位草稿链路上补齐「要求与证据 → 局部生成与有终点审阅 → 检查导出」三步，先修两个独立缺陷（F1/F2），全程不破坏 S1 冻结契约、S2 撤销边界、S3 绑定契约。

**Architecture:** 数据全部扩在 `docs-meta.json` 的 `meta.job` 子树（brief/evidence（refId 引用）/genTasks（两任务独立 taskId）/reviewPos + changes 增补字段 baseSnapshot/origText/appliedText/zone/evidenceRefs），无新数据文件。三时态（生成基线/应用前/应用后）与失效规则、guardOps 四检查、任务原子启动与旧回调拒绝——全部纯函数与既有 updateMeta 事务承载。UI 三入口共用之；候选应用统一走 S2 撤销链路。排版诊断基于渲染后 PDF 文本层（pdftotext），半自动 3 轮。

**Tech Stack:** 不变——Node ESM 零依赖、浏览器 ES5 注入层、bash+node 测试、playwright-core、poppler。
